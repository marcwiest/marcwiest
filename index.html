// Open source: @siteonce/astro-intl

An open-source Astro integration for multilingual content sites. Astro already handles locale prefixes and content collections. astro-intl adds what it leaves out: it pairs the same entry across locales so each translation keeps its own slug, injects localized routes like blog/{slug} and artikel/{slug}, and points hreflang tags, the locale switcher and the sitemap at the same document instead of the same path. A config that would publish a URL Astro can't serve fails at startup with an error that names the fix.

I built it spec-first with AI agents: agree on the spec, then docs, then tests, then code. MIT licensed.
